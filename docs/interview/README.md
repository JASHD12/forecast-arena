# Interview kit

Material for talking about Forecast Arena in interviews (working student / Werkstudent
roles in AI engineering, ML and data). Everything here describes what the repository
really does; when in doubt, the code and `docs/SPEC.md` win.

| File | Use it for |
|---|---|
| [pitch.md](pitch.md) | The 2-minute pitch, in English and German |
| [system-design.md](system-design.md) | Whiteboard walkthrough: components, data flow, guarantees, trade-offs |
| [questions.md](questions.md) | 40 likely questions with honest answers |
| [star-stories.md](star-stories.md) | Situation-Task-Action-Result stories from real incidents in this project |
| [cv-bullets.md](cv-bullets.md) | CV bullets and a LinkedIn project text |
| [numbers.md](numbers.md) | **Generated.** Every figure the kit quotes, with its source |

## Be open about how it was built

This repository was built by an AI coding agent working unattended under the owner's
direction, with the owner setting goals, approving changes and doing every human-only
step (`AGENTS.md`, `HUMAN_TODO.md`). Say so if asked; it is a strength when you can
explain every design decision, and the explainers in `docs/explainers/` and this kit are
there so that you can. Use "we" or "the system" where "I" would overstate your part.

## The rule for numbers

Never quote a number that is not in [numbers.md](numbers.md). That file is generated by
`scripts/interview_numbers.py` from the committed backtest model cards, the committed LLM
evaluation results and (with `--ledger`) the live ledger via `arena report cv`. A unit test
fails if a decimal figure or percentage in these files is missing from it.

Always say which kind of number it is:

- **Backtest**: past days replayed through the production code. Strong evidence about the
  classical models, but it is not the live record.
- **Evaluation**: a small frozen set of past questions sent to the real LLM. Useful for
  catching regressions (for example broken JSON), far too small to rank forecasters.
- **Live record**: the public ledger. Until the official record has run long enough the
  site says "too early to tell", and so should you.

Refresh before an interview:

```bash
git clone --branch ledger --single-branch https://github.com/JASHD12/forecast-arena.git /tmp/ledger
python scripts/interview_numbers.py --ledger /tmp/ledger
```
