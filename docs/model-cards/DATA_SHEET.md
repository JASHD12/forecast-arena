# Data sheet

Generated by `scripts/model_cards.py`. What the benchmark uses, under which terms. All data are public; the benchmark stores aggregates and values, never article text, and no personal data (Wikipedia articles about people are excluded, SPEC 7.3). Verified facts and dates are in `docs/SOURCES.md`.

| Data | Attribution | Licence or terms |
|---|---|---|
| Electricity day-ahead prices | Bundesnetzagentur | SMARD.de | CC BY 4.0 |
| Weather observations and forecasts | Deutscher Wetterdienst (DWD), via Bright Sky | CC BY 4.0 |
| Wikipedia page views | Wikimedia Foundation pageview statistics (wikimedia.org REST API) | see docs/SOURCES.md |
| Exchange rates | European Central Bank, euro foreign exchange reference rates (log returns computed by Forecast Arena) | free use, cite the ECB |
| Crypto prices | Data provided by CoinGecko (coingecko.com) | CoinGecko API terms, attribution required |
| News tone and headlines | Data: GDELT Project (gdeltproject.org) | GDELT terms: free use, cite the GDELT Project and link https://www.gdeltproject.org/ |

Questions are generated by code from this data each evening and locked at 09:30 UTC; outcomes come from the same sources, with a grace period before a question is voided.
