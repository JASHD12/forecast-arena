# Model card: AI agent (LangGraph) (`agent_graph`)

Generated by `scripts/model_cards.py` from the catalog, the standings snapshot and the source modules. Research project, not advice.

- **Kind:** ai, labelled AI
- **Status:** live; switch: `ARENA_AGENT_GRAPH`

## Intended use

A language-model forecaster in a public research benchmark of tomorrow's yes/no questions. Its probabilities are experiments, not advice; its text may be wrong.

## Data

**What it sees:** As agent, run as a LangGraph graph: plan, retrieved evidence, tools, self-check.

**Which questions it answers:** 1 question per topic per day.

Every input goes through the as-of gateway, so it sees only data published before the forecast time (integrity rule I3). Sources and licences: [DATA_SHEET.md](DATA_SHEET.md).

## Metrics

Not part of the headline set (`base_rate`, `ml`, `llm_context`, `agent`), so the snapshot has no live number for it. See the Lab page and `docs/lab/` for its pre-registered evaluation, if it has one.

## Limits

It can hedge toward the base rate, can be wrong with confidence, and costs tokens. A replay of its behaviour cannot reproduce every tool (news, retrieval).

## Monitoring

Daily token cap (tested to equal the workflows), recorded skips with reasons, tool-call and latency tables on the LLM page, health check roster.
