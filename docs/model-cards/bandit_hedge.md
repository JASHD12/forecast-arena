# Model card: Learned blend of forecasters (experimental) (`bandit_hedge`)

Generated by `scripts/model_cards.py` from the catalog, the standings snapshot and the source modules. Research project, not advice.

- **Kind:** combiner
- **Status:** experimental, outside the headline board; switch: `ARENA_BANDIT`

## Intended use

A forecaster built only from the other forecasters' probabilities.

## Data

**What it sees:** The other forecasters' forecasts of the same question, blended with weights learned online from resolved questions (Hedge; experimental).

**Which questions it answers:** every question with two or more forecasts.

Every input goes through the as-of gateway, so it sees only data published before the forecast time (integrity rule I3). Sources and licences: [DATA_SHEET.md](DATA_SHEET.md).

## Metrics

Not part of the headline set (`base_rate`, `ml`, `llm_context`, `agent`), so the snapshot has no live number for it. See the Lab page and `docs/lab/` for its pre-registered evaluation, if it has one.

## Limits

It cannot be better than its members on average and inherits their blind spots.

## Monitoring

It writes nothing until enough resolved forecasts exist (SPEC 8); health roster.
