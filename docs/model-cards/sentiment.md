# Model card: News-tone model for crypto (experimental, backtest only) (`sentiment`)

Generated by `scripts/model_cards.py` from the catalog, the standings snapshot and the source modules. Research project, not advice.

- **Kind:** ml
- **Status:** experimental, outside the headline board; switch: always on

## Intended use

A classical statistical model forecasting yes/no questions about tomorrow for a public research benchmark. Not for trading, energy purchasing or any decision about people.

## Data

**What it sees:** The ml probability of the same crypto question and the news tone and article count of the days before it (GDELT, aggregate numbers only, each day counted 12 hours after it ended); backtest only so far, not running live (experimental).

**Which questions it answers:** crypto questions.

Every input goes through the as-of gateway, so it sees only data published before the forecast time (integrity rule I3). Sources and licences: [DATA_SHEET.md](DATA_SHEET.md).

## Metrics

Not part of the headline set (`base_rate`, `ml`, `llm_context`, `agent`), so the snapshot has no live number for it. See the Lab page and `docs/lab/` for its pre-registered evaluation, if it has one.

## Limits

It sees only the as-of numbers in its context (no news, no outages); fixed or fitted error models can be too wide or too narrow; direction questions on prices are held at 50%.
