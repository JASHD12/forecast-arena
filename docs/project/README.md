# Project management files

How this repository is run. It was built by an AI coding agent working under the owner's
direction (see [`AGENTS.md`](../../AGENTS.md)); these files are its shared memory with the
owner, kept in the open on purpose.

| File | What it is |
|---|---|
| [TASKS.md](TASKS.md) | The ordered backlog with dependencies and "Done when" checks (`scripts/status.py` reads it) |
| [PROGRESS.md](PROGRESS.md) | Current state, done log, open risks |
| [DECISIONS.md](DECISIONS.md) | Design decisions with context and alternatives |
| [HUMAN_TODO.md](HUMAN_TODO.md) | Steps only the owner can take (accounts, settings, legal text) |
| [START_HERE.md](START_HERE.md), [KICKOFF_PROMPTS.md](KICKOFF_PROMPTS.md) | How the project was set up |
