The research question

When does an LLM agent beat a classical model?

An honest "it does not" is a valid result. Four hypotheses were written down before any data existed and are judged only by the official record:

  1. On numeric topics (electricity, weather), classical ML beats every LLM.
  2. On news-driven topics (Wikipedia attention), the tool-using agent beats ML.
  3. Nobody beats the base rate on exchange-rate direction.
  4. The ensemble is at least as good as the best single forecaster.

What this project demonstrates

  • LLM engineering

    Claude via the official SDK, a tool-using agent, strict JSON contracts, prompt versioning, injection hygiene, hard cost caps.

  • Machine learning

    Gradient-boosted quantile regression and classification, Platt calibration, time-series cross-validation without leakage.

  • Statistics

    Proper scoring rules, reliability diagrams, Murphy decomposition, day-block bootstrap, Diebold-Mariano.

  • MLOps

    Model registry, weekly champion/challenger retraining, MLflow tracking, Evidently drift, permutation importance.

  • Data engineering

    Five live APIs, an as-of gateway, idempotent jobs, an append-only hash-chained ledger, DuckDB SQL and Parquet.
