Worum es geht

Jeden Morgen erzeugt das System Ja/Nein-Fragen über den nächsten Tag aus öffentlichen Daten, zunächst zu den deutschen Day-Ahead-Strompreisen (Bundesnetzagentur, SMARD). Beispiel: „Liegt der durchschnittliche Strompreis morgen über 80 €/MWh?“ Mehrere Prognosemodelle geben jeweils eine Wahrscheinlichkeit ab, bevor die Antwort feststeht. Am nächsten Tag kommen die echten Daten, jede Prognose wird bewertet, und diese Website zeigt die Ergebnisse.

Wer prognostiziert

  • Basisrate: wie oft die Antwort früher „Ja“ war – der Maßstab, den alle schlagen müssen.
  • Persistenz: „morgen wie heute“.
  • ML-Modell: Gradient Boosting, trainiert auf vergangenen Daten, mit kalibrierten Wahrscheinlichkeiten.
  • Sprachmodelle (LLM): Claude mit nur der Frage oder zusätzlich mit den aktuellen Daten.
  • KI-Agenten: ein LLM, das vor der Antwort Werkzeuge nutzt (Daten, Nachrichten, ähnliche frühere Fragen), einmal selbst geschrieben und einmal mit LangGraph.
  • Offenes Modell: ein kleines Open-Weight-Modell, das kostenlos auf der CPU läuft.

Warum man den Zahlen trauen kann

  • Alle Fragen und Prognosen werden um 09:30 UTC gesperrt und in ein nur erweiterbares, öffentliches Protokoll auf einem Git-Branch geschrieben. Jeder Tag wird mit SHA-256-Hashes verkettet; jede nachträgliche Änderung wäre sichtbar.
  • Prognosemodelle sehen nur Daten, die zum Zeitpunkt der Prognose bereits veröffentlicht waren (kein „Blick in die Zukunft“).
  • Bewertet wird mit dem Brier-Score: (Wahrscheinlichkeit − Ergebnis)², kleiner ist besser; 0,25 erreicht, wer immer 50 % sagt. Ein Unterschied gilt erst als belegt, wenn sein 95-%-Intervall die Null ausschließt; vorher steht dort „zu früh für ein Urteil“.
  • Fällt ein Modell aus, wird ein Auslassen mit Grund gespeichert – niemals eine erfundene Zahl.

Technik

Python, scikit-learn, LightGBM, PyTorch, DuckDB, dbt, FastAPI, die Anthropic-API, LangGraph, RAG mit lokalen Embeddings, LLM-Evaluation und Tracing, ein MCP-Server, Docker, Kubernetes (in CI geprüft), Airflow (in CI geprüft) und GitHub Actions. Alles läuft kostenlos auf GitHub Actions und GitHub Pages; die KI-Nutzung kostet etwa einen US-Dollar im Monat. Details mit Links zum Code: For recruiters.
