Experiments

Every weekly retraining run, newest first. Each run trains a candidate model per domain, scores it next to the current model on the last 28 days of real questions, and promotes it only if it is not worse (rule in src/arena/ops/weekly.py). The runs are logged with MLflow to a file; this page shows the summaries that each run publishes to the public ledger.
