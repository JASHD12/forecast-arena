  1. 1

    Questions about tomorrow

    Every evening around 18:00 UTC the system publishes yes/no questions from live public data, and the next morning around 05:30 UTC every forecaster answers them before the 09:30 UTC lock. The questions are about: German electricity prices, the weather in four German cities, attention to Wikipedia articles and exchange rates.

  2. 2

    Forecasts before the facts

    Each forecaster publishes a probability that the answer is YES. At 09:30 UTC everything locks. Forecasts are written to a public, append-only ledger, so nobody can change them later.

  3. 3

    Reality keeps score

    When the official data is published, usually the next day, each question resolves YES or NO and every forecast gets a score.

Who is forecasting?

Base rate

How often the answer was YES for this kind of question in the past. The yardstick everyone must beat.

Same as last time

Assumes tomorrow looks like the most recent answer to the same question.

ML model

A classical statistics or machine-learning model per topic, trained only on data that existed at forecast time.

AI, question only AI

A large language model that sees only the question and the rules, no data.

AI with data AI

The same model, also given the recent data the ML model sees.

AI agent with tools AI

The model with data plus a few read-only tools, such as news headlines and a Wikipedia summary.

How do I read "70%"?

70% means: of all the times a forecaster says 70%, about 7 in 10 should come true. A single question can't prove a forecaster right or wrong. Only many questions can, which is why the Calibration page plots said-versus-happened.

What is the Brier score?

For each question: take the probability given to what actually happened, subtract it from 1, square it. Lower is better.

Forecast for YESAnswerBrierReading
90%YES0.01confident and right: excellent
50%either0.25a coin flip: the "know-nothing" score
90%NO0.81confident and wrong: heavily punished

So a forecaster only beats the coin flip if its average stays below 0.25, and it only beats the base rate if it is lower than the base rate's average on the same questions.

Check it yourself in five commands

You do not have to trust this site. With Python 3.12, git and make:

  1. Get the code: git clone {{ repo_url }}.git, then cd forecast-arena and make setup.
  2. Get the public record: git clone --branch ledger --single-branch {{ repo_url }}.git _ledger.
  3. Recompute every file hash, seal and lock time: .venv/bin/arena --ledger-dir _ledger ledger verify. It prints PASS or the exact problem.
  4. Check from the Git history that each day's forecasts were committed before their lock: .venv/bin/arena --ledger-dir _ledger ledger verify --git.
  5. Rebuild this whole site from the record and compare: .venv/bin/arena --ledger-dir _ledger site build --out my_site.

The Git check is strong evidence, not proof: commit times are set by the committer. Together with the hash chain, public clones and the GitHub Actions logs, a silent edit would be visible.

Frequently asked questions

Why only yes/no questions?

They can be scored fairly and simply, and they make different kinds of forecasters directly comparable.

Why does it say "too early to tell"?

Differences between forecasters are only called real when a 95% interval excludes zero, which needs at least 30 official days. Until then the honest answer is that we don't know yet.

What is the "rehearsal"?

The first days, while the pipeline proves itself. They are shown for transparency but excluded from the headline scores. The official record starts automatically after five clean days in a row.

Can I check that nothing was changed afterwards?

Yes. Every question, forecast and outcome is a file on the public ledger branch, sealed with a hash chain, and git records when each was written. The README explains the two commands that verify it.

Is this investment or energy advice?

No. It is a research benchmark. The probabilities are experimental outputs and may be wrong.

Why are there no stock-price questions?

Stock and index prices are licensed data; we found no free source whose terms allow publishing them here. Publishing daily predictions about named shares could also fall under EU market-abuse rules for investment recommendations.

What happens if a forecaster fails?

The failure is recorded as a skip with a reason (see Status). Nobody fills in a 50% guess.

Does this site track me?

No cookies, no analytics, no third-party scripts or fonts. See Privacy for what the hosting provider logs.

Can I take part?

A human panel that forecasts the same questions is planned. Follow the feed or the repository for news.
