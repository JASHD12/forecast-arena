How the scores are computed

Brier and log scores are lower-is-better, on probabilities clipped to [0.01, 0.99]. Intervals are 95% day-block bootstrap intervals (questions from the same day are correlated, so days are resampled). A difference is called supported only when its interval excludes zero. With fewer than 30 official days or 300 resolved common-set forecasts every board says "too early to tell". The common set contains only the questions every forecaster in the group answered, so the comparison is fair.
