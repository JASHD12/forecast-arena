What this site does and does not do

  • No cookies, no local storage, no analytics, no tracking pixels.
  • No third-party requests: no external fonts, scripts, images or embeds. Every file comes from this site.
  • No forms and no accounts: the site does not ask you for any data.
  • No personal data in the content: questions are about prices, weather, exchange rates and Wikipedia articles; articles about people are excluded by design.

Hosting

The site is a static website served by GitHub Pages (GitHub, Inc.). According to GitHub's documentation, when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes. This happens on GitHub's side; this project has no access to those logs. See the GitHub Privacy Statement.

Links to other sites

Links to data sources and to GitHub are ordinary links; nothing is loaded from them until you click. The site asks browsers not to send referrer information.

Human panel (planned)

If a human forecasting panel starts, its members will be told in advance and in writing what is stored (a pseudonym, their probabilities and submission times), that it is published permanently in an append-only public record, and they must agree before taking part.
