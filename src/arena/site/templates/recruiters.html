What it is

Every day the system publishes yes/no questions about the near future from public data (electricity prices first), the evening before they lock. Baselines, a gradient-boosting model, LLM forecasters and two LLM agents each publish a probability before the answer exists, into an append-only, hash-chained public record. The next day the answers arrive and every forecast is scored with proper scoring rules. It runs entirely on GitHub Actions and Pages for about one US dollar a month of AI usage.

Measured so far: see the backtests (a year of replayed past days, clearly labelled as not live), the LLM evaluation (it found and fixed a real bug) and the live leaderboard, which says "too early to tell" until the statistics can decide.

Five things worth 30 seconds

  1. Verify the record yourself. One command re-checks every hash and that no forecast was written after its question locked.
  2. A year of backtests. The champion model against baselines and challengers (LightGBM, a PyTorch network, Chronos, SARIMAX, ETS), losers included.
  3. The eval that caught a bug. A frozen golden set showed answers cut off by an output cap{% if json_change %}; first-try valid JSON went from {{ json_change.before }} to {{ json_change.after }}{% endif %}.
  4. The architecture. Live data with an as-of gateway against look-ahead, an append-only ledger, proper scoring, MLOps, CI-gated releases.
  5. Read the agent loop. A tool-calling agent whose limits (calls, time, tokens) are enforced by the harness, not the prompt.
